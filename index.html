      Política de Privacidade

      Última atualização: outubro de 2026.

      Esta Política explica quais dados pessoais este site coleta, para que servem e quais são os seus direitos, de acordo com a Lei Geral de Proteção de Dados (Lei nº 13.709/2018 - LGPD).

      1. Quem é a responsável pelos dados

      Paloma Ribeiro, criadora de conteúdo UGC, com contato pelo e-mail paalomazevedo@gmail.com, é quem decide como e por que os dados coletados neste site são usados.

      2. Quais dados são coletados

      • Formulário de contato ("Me conta da sua marca"): nome, e-mail e a mensagem que você escrever.
      • Pop-up de mídia kit: nome e e-mail, só se você preencher e enviar.
      • Navegação no site: um registro simples de qual página foi aberta e de onde a visita veio (por exemplo, Instagram ou Google), sem nenhum dado que identifique você pessoalmente.

      O site não usa cookies de rastreamento nem pixels de publicidade. Guarda só duas informações no seu próprio navegador (nunca enviadas pra fora dele): o idioma escolhido (português/inglês) e se o pop-up de mídia kit já apareceu nessa visita.

      3. Para que esses dados são usados

      • Responder ao seu contato e conversar sobre uma possível parceria;
      • Enviar o mídia kit, quando solicitado;
      • Entender, de forma agregada, quais páginas e origens trazem mais visitas ao site.

      4. Com quem os dados são compartilhados

      Os dados ficam guardados no banco de dados do site (Supabase) e, quando aplicável, passam pelo serviço usado para enviar e-mails (Resend). Nenhum dado é vendido ou compartilhado com terceiros para fins de publicidade.

      5. Seus direitos

      Você pode, a qualquer momento, pedir para saber quais dados seus estão guardados, corrigi-los ou pedir a exclusão deles, escrevendo para paalomazevedo@gmail.com.
